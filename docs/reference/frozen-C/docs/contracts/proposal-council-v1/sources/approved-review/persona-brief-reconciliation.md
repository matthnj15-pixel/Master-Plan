## Explicit tags and common profile rules

| Required tag | Meaning and allowed use |
|---|---|
| **simulated fact** | Actual observation from a current engine snapshot or computation, with source ID and engine revision. An unimplemented fixture overlay is not a simulated observation. |
| **scenario-authored rule** | Proposed authored initial fact (`kind:'authored_fact'`), priority/stance predicate or authority rule (`kind:'authored_rule'`). Requires review; source evidence may motivate the content but does not make it a law or a current engine result. AUTHOR-FIXTURE origin stays explicit. |
| **character belief** | An attributed expectation, worry or suspicion. Include `suspected:true` when unverified. It cannot establish ownership, a constraint, factual claim credit or a binding commitment. |
| **flavor** | Voice and biography without material effects. It cannot silently alter authority, weights, cost or stance. |
